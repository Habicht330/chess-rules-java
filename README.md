# Chess Rules — Java 21

Учебная библиотека правил шахмат и консольная демонстрация. База: представление позиции, закрытая sealed-иерархия фигур, перечисления, генерация легальных ходов, шах, мат, пат, рокировка, взятие на проходе, превращение пешки и запрет ходов, оставляющих собственного короля под шахом.

## Требования
- JDK 21
- Maven 3.9+

## Запуск
```bash
mvn test
mvn package
java -cp target/classes ru.example.chess.Main
```

## Структура
- `Piece` и шесть record-фигур — закрытая иерархия и полиморфный `type()`.
- `Square` и `Move` — неизменяемые значения с проверкой инвариантов.
- `Position` — неизменяемый снимок состояния.
- `ChessRules` — легальные ходы, проверка шаха и выполнение хода.
- `InvalidMoveException` — объясняет отказ выполнить ход.
- `Main` — консольная демонстрация на начальной позиции из 32 фигур.
- `ChessRulesTest` — тестовые сценарии JUnit 5.
